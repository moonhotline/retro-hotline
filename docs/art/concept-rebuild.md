# Retro Hotline · 九张原图重构提示词

使用同一验收方法。把每张原图作为构图基准，锁定评审机位，再单独检查几何轮廓、近中远景遮挡、材料高光和冷暖关系。原图仅用于并排检查。实际场景以可绕看的网格、可重打光的材质和场景光源构建。

## 复核与发布

- 采用 `frontend/lab/catalog.ts` 的机位作为评审快照。建筑以 16:9 视口复核，机械以 4:3 视口复核。相机可旋转检查遮挡后的结构，开启「对照概念图」可回到评审机位。
- 白场、材质实验与概念模型分别持有场景状态。概念按需导入，旧选择的异步导入完成后会丢弃。退出场景时释放几何、材质、平面反射和预滤波环境贴图。模型重建过程使用固定随机种子。
- 发布前用浏览器检查 WebGPU 和强制 WebGL2，逐项验证九个模型、来回切换、缩放、对照和机械核心破裂。自动测试校验每个概念的总三角面数及可渲染网格的最低密度。相似度由并排快照逐图复核。
